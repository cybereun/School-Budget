# 학교회계 예산현황판

브라우저에서 에듀파인 원본 엑셀을 분석하는 로컬 전용 예산 대시보드입니다.

## 실행

`index.html`을 브라우저에서 직접 열거나, 폴더에서 아래처럼 정적 서버를 실행합니다.

```text
python -m http.server 4173
```

이후 `http://127.0.0.1:4173/`을 엽니다. 별도 백엔드나 API가 필요하지 않습니다.

## 지원 파일

- 사업관리카드(예산·현액)
- CSV·TSV·ODS 등 표 형식 원본 자료
- `.xlsx`, `.xls`, `.csv`, `.ods`

업로드한 파일은 SheetJS로 현재 브라우저 안에서만 읽습니다. 집행계획과 메모는 브라우저의 localStorage에만 저장되며, 엑셀 원본은 저장하지 않습니다.

담당자 열이 있는 파일은 담당자명을 자동으로 나누어 선택할 수 있습니다. 한 항목에 여러 담당자가 있으면 각 담당자에게 함께 표시하고, 공란·미지정 항목은 `담당자 미지정`으로 따로 볼 수 있습니다.

사업 탐색에서는 세부사업 → 세부항목 → 산출내역을 클릭해 아래로 펼쳐 볼 수 있습니다. 그래프 보기에서는 현재 잔액 비율에 따라 초록·주황·빨강으로 표시하며, 계획 입력하기에서는 산출내역별 앞으로 사용할 금액을 저장할 수 있습니다.
